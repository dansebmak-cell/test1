# SheetToStore 24h

Done-for-you e-commerce catalog cleanup. We turn messy supplier CSV, Excel, and PDF files into validated, SEO-enriched Shopify and WooCommerce CSVs in 24 hours.

The landing page is `index.html` at the repository root, ready for GitHub Pages. An empty `.nojekyll` file is included so Pages serves the static files as-is.

## Sample files

- `sample_messy_supplier.csv` — a raw supplier export (duplicates, mixed currencies, encoding issues, inconsistent stock).
- `sample_shopify_clean.csv` — the same catalog after cleanup and SEO enrichment, in Shopify CSV format.
